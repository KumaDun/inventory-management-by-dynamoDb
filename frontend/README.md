# Frontend

Standalone inventory frontend built with React 19, Vite, Tailwind 4, and shadcn primitives.

## Run

```bash
npm install
npm run dev
```

The app expects the inventory API at `http://localhost:5000/api`.

## Notes

- This frontend is intentionally separate from `web/web`.
- The UI is dashboard and card driven instead of the existing table-first admin layout.
